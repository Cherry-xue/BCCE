# BCCE — 杀戮尖塔 2 原版角色卡牌拓展

BCCE 为《杀戮尖塔 2》的五名原版角色添加新卡牌与能力，围绕力量、消耗、中毒、辉星、奥斯提和充能球等机制，丰富构筑选择。

- 新卡牌加入各角色的原版卡池，可在正常游戏中获取。
- 包含多人专属卡牌，例如「火山」「华尔兹夜曲」「不明飞行物」「指挥」和「黑客」，提供共享抽牌、生成卡牌、召唤和充能球等协作效果。
- 目前仅提供简体中文卡牌与能力说明，并陆续补充卡图和能力图标。

需要先安装前置模组 [RitsuLib](https://github.com/BAKAOLC/STS2-RitsuLib)。

目前基于游戏 beta 版开发，卡牌效果与平衡性仍在测试和调整中。
